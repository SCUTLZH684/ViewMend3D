# v1 候选日志：CPU 探索性诊断与 v2 假设

范围：Replica office0、v1 已完成的固定观测/固定任务时间实验。仅标准库读取既有 JSON；没有读取候选真值、重跑渲染/重建、占用 GPU 或改动仓库/旧产物。所有 821 个读取输入的 SHA-256 与已通过 fresh 审计的原 v1 输入一致，结束时也再次核对读取稳定性。

**这是一份事后 office0 评分机制诊断。regret 是同一候选组内放弃的基线评分，不是实际重建误差。离线 λ 网格没有得到新重建质量，不能据它挑“最佳质量参数”。**

本轮只执行已预注册的 [v2有界奖励协议](../optimization-v2.md)。以下其他假设留待另轮验证，不在本轮按结果临时扩展。

## 字段与评分定义

可用字段包括 raw base/defect、exploration/uncertainty、reachable、path_lengths、最终分数、valid_fraction、positive_fraction、geometry_active，以及 sampling/utility/path_scoring 三段计时。candidate_poses 仅用于确认日志字段存在，没有读取其未来观测或候选 GT。valid_fraction 是当前地图渲染后通过支持/深度/邻域条件的像素比例；D 是不确定性加权的法线不一致热图均值，不是真实错误率。

只在 reachable 候选上令 b=N(B)、d=N(D)、c=N(path)，κ=0.5。记录的 λ=0.5 且所有几何事件都激活：

- 基线分数：s₀=b−κc。regret=max(s₀)−s₀(实际选中)。
- v1 分数：(b+λd)/(1+λ)−κc。等价排序为 b+λd−(1+λ)κc。
- 因此 λ 同时改变几何混合和路径相对基线的强度；λ=0.5 等价于未再次归一化形式的路径系数 0.75。该机制与声明公式一致，是可重新明确的设计选择，不是已证明的实现错误。

## 能由日志支持的 v2 假设

1. **限制几何项放弃的基线效用。** 单独冻结较弱λ或同组base-score regret限额/近基线候选重排规则，保留探索B与路径结构。支持依据是大量改选与较高几何占比；验证必须重新做完整重建和同种子质量/成本比较，不能以本离线regret取代质量验收。

2. **让可靠性权重看绝对量与集中度。** 明确当前最低peak/最小valid门槛在v1都没有触发；可预先定义依raw peak、总量、有效候选数等连续衰减规则，防止很弱的D被归一化成固定权重。后期signal变弱但依旧改选支持此问题存在，未证明任一具体阈值能修复质量。

3. **将路径系数与几何混合的定义写清并单独消融。** 当前λ与路径相对B耦合已由代数及日志确认。若v2选择其他参数化，应固定一个方案及对照，重新验证路径、覆盖与质量；当前离线解耦结果没有显露质量优势。

4. **优先剖析utility计算，而非盲目删诊断IO。** 后缀每事件utility约0.317/0.417秒，占规划约80%/83%。可先增加低成本分段计时或对固定记录的地图/候选测量渲染/几何开销，再设计等信息边界的批处理/预筛；改变候选数或评分精度时需为baseline同步设对照，不能借更小工作量称算法提速。

多场景验证与阈值选择需另立验证/测试划分。office0事后λ网格只能定下一轮预注册假设，不能反复选参后声称泛化。以上未执行新的GPU优化/实验。
