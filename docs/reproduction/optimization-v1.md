# ViewMend3D 第一版优化验证记录

更新日期：2026-10-06。执行依据为 [优化框架 v1](../optimization-framework.md)。第一版算法、受控实验入口、消融、指标审计与网页支持已经实现；**新增 GPU 闭环和优化效果尚未验证**。本记录不能替代实际对照结果。

## 1 已完成的实现

| 模块 | 实现 | 依据 |
| --- | --- | --- |
| 几何缺陷评分 | 低置信度加权的有向法线不一致，稳定深度门控、弱信号回退 | `src/viewmend3d/scoring.py` |
| 公平规划器 | 不查询候选模拟器；统一 ROI、路径成本、可达候选归一 | `src/viewmend3d/planner.py` |
| 公共前缀 | 保存并恢复实际地图、训练 RGB-D、体素图、相机、路径、随机状态 | `src/viewmend3d/benchmark.py` |
| 随机性 | 规划、传感器噪声和建图按域与事件独立播种 | `src/viewmend3d/randomness.py` |
| 对照消融 | confidence、匹配随机、新评分、无深度门控、仅优化 | 独立 benchmark 入口，保留原作者入口 |
| 评估与审计 | 固定表面采样种子、原单位定义、完整产物链、配对一致性 | evaluator 与 `aggregate_benchmark.py` |
| 网页 | 方法/种子/协议、采集和更新计数、对比表、真实可选诊断 | manifest v2，旧结果兼容 |

原始 ActiveGS 源码仍只含已记录的两行多进程启动修复，新算法位于独立扩展。公平入口额外处理 ROI 上限、不可达候选、零位移和路径末姿态；这些共同处理不能归为缺陷评分的贡献。

## 2 检查结果

已在服务器隔离环境中隐藏全部 CUDA 设备执行 **49 项检查，全部通过**：评分与规划适配 17 项、协议 7 项、真实随机域隔离 2 项、结果审计 6 项、网页控制 8 项、导出兼容 9 项。该检查包含测试替身，验证公式与接口，未执行 CUDA 渲染或新方法的三维重建。

补充审查修复了跨种子结果可能混合不同场景或配置的审计缺口。分支现记录场景名称、场景网格 SHA-256 与公共前缀配置上下文哈希；汇总和网页配对会检查这些身份。汇总还要求产物验收已通过，且与指标的阶段和实际观测数对应，避免把“已写出指标但验收失败”的实验视为完成。受控入口显式固定每次建图为协议声明的 10 步优化。

另执行 [实际类前缀 CPU 检查](../../scripts/activegs/check_prefix_cpu.py)，验证 9 个 Gaussian 状态张量、含缺失深度标记的原始 RGB-D/相机参数、体素图、记录器时间与轨迹保存恢复一致，两个分支张量存储独立，恢复后可重建 5 个 Adam 参数组并执行 CPU 梯度更新。检查从固定上游 AST 提取实际类体，避开模块导入时的 LPIPS CUDA 初始化；类方法未改写。执行全程未初始化 CUDA。这补充了状态和接口证据，仍不证明真实渲染、完整建图或质量提升。

独立源码审查发现上游的小转角插值会只返回起始姿态，导致选中的视角与实际观测不一致。受控入口现统一追加目标末姿态，传感器采集后检查实际相机参数；新增回归测试通过。热力图保留在计算设备，只搬运选中图像，搬运及写盘单列为诊断开销。

对此前真实 GPU 产物执行了新版导出：5 个阶段、186 个采集相机、2,930 个运动路径位置均保持一致。作者的浮点阶段编号已兼容，并直接用仓库保存的真实指标文件做回归。Edge 测试验证三维加载、首末阶段、曲线联动、显示开关；无页面错误，390 px 无横向溢出。网页中的指标仍来自此前原作者流程，不能解释为新方法结果。

EGL 设备元数据查询确认当前驱动会根据 CUDA 可见设备重新编号；未添加 GPU 选择源码补丁。此检查未创建渲染上下文，非零物理 GPU 的完整渲染仍需实际验证，见 [设备映射记录](evidence/egl-device-mapping.json)。
