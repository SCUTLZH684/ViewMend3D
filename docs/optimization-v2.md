# ViewMend3D v2 优化框架与预注册协议

制定日期：2026-10-06。状态：CPU分析与实现阶段，尚未执行v2 GPU实验。执行前固定本文件、配置与源码，不根据开发结果临时换主方法、调参或挑种子。v1源提交、状态、缓存、负结果与历史展示保留。

## 依据与待检验假设

[v1完整结果](reproduction/optimization-v1-results.md)显示原Defect未稳定改善质量。其最终候选评分在基础效用和几何项非零时为 `(p + λq)/(1+λ) − ηc`：p为可达候选上的基础效用归一值，q为几何项和归一值，c为路径和归一值。λ=0.5把p系数从1降至2/3，路径系数仍为η=0.5。两项相对权重因此发生变化；不能仅把最终差异解释为“几何缺陷的贡献”。

构造反例B=[55,45]、L=[57.5,42.5]、D=[0.1,0.1]时，baseline选0，v1选1。它是评分机制例，不是重建质量证据。真实v1后缀诊断中Defect选择的baseline-score regret均值约0.0085/0.0087（固定观测/固定时间），几何项全程激活。这提示应约束对基线排序的偏离，但尚未证明它是退化的唯一原因。

v2假设：保持baseline最终分数与路径惩罚，在其上加保守、有界的当前地图几何奖励，可以减少低价值改选；批量几何计算可能降低额外开销。两项均是待验证假设，CPU回放和构造例不等同于真实重建改善。

## 固定评分方案

新增方法标识`defect_guarded`，消融为`defect_guarded_no_gate`。旧`defect`及作者入口的规则不变。两者沿用v1几何代理与阈值：有向法线残差死区0.05、不透明度≥0.7、法线范数>0.5、有效面积≥1%、最小peak为10⁻⁴。主方法保留深度跳变门控，消融仅移除该门控。

只在可达候选集合R计算，n=|R|：

```text
p = N(B)，c = N(L)，S0 = p − 0.5c
δ = β/n，β = 0.1（预先固定的保守工程初值）
q_i = clip(clean(D_i)/max_R(clean(D)), 0, 1)
S2_i = S0_i + δ q_i
```

S2不再次归一化，不改变路径系数。无需另加等价的regret候选门控；有界非负奖励已保证所选候选j满足`max_R(S0) − S0_j ≤ δ`（实数算术；实现检查浮点容差）。这只是基线代理分数损失上限，不保证几何质量。β未使用留出指标或事后质量网格选择，不能声称最优。

β=0、弱/全零几何项、常量几何项、基础效用全零时返回同一次baseline评分。基础全零沿用baseline已有随机回退，只抽一次；常量D不应改变选择。不可达候选不能参与Dmax或奖励。记录原S0、奖励上限/逐候选奖励、实际regret、基线/最终索引、信号回退原因、基础效用和路径差。

新方法复用100次基础候选渲染，保存必要当前地图通道，再用已有支持batch的几何函数批量计算D；不额外调用模拟器或渲染未来观测。需要额外临时显存，必须实测峰值和完整规划时间，不能仅凭kernel数量宣称加速。保留所有方法100候选、最多30 ROI、每事件10优化步、相同建图及TSDF配置。旧v1逐候选计算保持。

## 数据、开发与留出边界

本轮只用已安装Replica office0。v1种子0/1/2已用于探索，属于开发证据；v2开发用预先指定0/1以控制运行量，不因其结果好坏筛选。留出确认使用未用于方案设计的种子3/4/5，主方法固定为defect_guarded，不能根据开发阶段改成消融赢家。种子留出只测试同场景新随机运行，不是新场景或跨场景泛化。

不复用v1原始baseline结果；每个v2阶段重新生成同源公共前缀，所有方法恢复其真实地图、训练RGB-D、体素、相机、路径与RNG。未来候选真值RGB-D、掩码和参考网格误差不得用于规划；已知包围盒作为共有公开先验，参考网格只供评估。原随机域定义保持兼容；v2完整评分recipe、阶段spec与摘要进入前缀context和协议记录。

## CPU与GPU验收

先验证常量D不改选、β=0的精确baseline/RNG等价、无效D/路径/全零边界、不可达高D隔离、有界regret、batch与逐视角的几何值/掩码一致。测试应覆盖公式反例和真实日志的无GT回放；不把这种回放称为新重建。

受控入口必须记录v2 recipe与spec摘要，拒绝方法/seed/配置缺失、来源变化、旧前缀或混预算汇总。共享调度和只读界面需识别v1/v2，不能使新worker对旧入口不可见。GPU smoke需要真实非空地图与网格、诊断、正确采集位姿、无未来调用、奖励/regret上限及所有新方法导出。

## 结果判据与交付

四个正式阶段分别统计，不把开发n=2与留出n=3合并或把不同预算混用；均值±样本SD是描述统计，不是置信区间。报告各seed的Accuracy/Completion(cm)、2cm覆盖率(%)、Chamfer(mm)、同seed配对差，以及规划/建图/任务/墙钟/观测/路径/诊断/网格评估成本和Torch峰值。完整任务时间定义沿用v1。

重点检验留出Completion和覆盖率，Accuracy、Chamfer与成本同时作为约束。若只在开发改善、只改善部分指标、或更少采集伴随较低耗时，按实际权衡报告；不宣称稳定质量改善或等质量加速。未获得提升也保留全部数据，下一轮另立协议。全部通过后更新文档、真实网页结果与历史汇总，commit并push，然后停止本轮定期检查。
